# Simulation Outputs

Run the integration testbench to generate `amtgc.vcd` where supported. Run the standalone timer and junction testbenches to generate `timer.vcd` and `junction.vcd`.

Recommended evidence screenshots:
1. Timer count and done pulse.
2. Junction FSM sequence and all-red gap.
3. Pedestrian phase.
4. Emergency all-red behavior.
5. Green-wave trigger/offset.
6. Adaptive green timing at low and maximum density.
7. Self-checking console PASS output.
